# Expense Tracker Project

## Project Purpose
This is a simple browser-based Expense Tracker used for training.

## Development Rules

- Use only HTML, CSS and vanilla JavaScript.
- Do not introduce React or external frameworks.
- Keep the application beginner-friendly.
- Use clear variable and function names.
- Validate all user input.
- Never insert user input directly using innerHTML.
- Explain major code changes before implementing them.
- Do not modify the visual design unless explicitly requested.

## Currency

- All monetary values should be displayed in Indian Rupees (₹).
